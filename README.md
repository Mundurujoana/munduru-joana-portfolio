# Munduru Joana – Portfolio

This portfolio is a frontend-only Next.js app.

## Run locally

```sh
npm install
npm run dev
```

The app runs at http://localhost:3000.

Edit `data/portfolio.ts` to update the profile, projects, and experience. Add your CV at `public/Munduru-Joana-CV.pdf`.

The contact form opens a prefilled message in the visitor's email app; it does not send or store messages on a server.
